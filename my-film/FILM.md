# 青山 · 15 秒循环短片

一个茶叶品牌的片头 / 循环海报片。墨落纸、纸成山、山化叶、叶归墨、墨复落 —— 首尾落在同一滴墨上，可以无缝循环播放。

- 工程：Remotion（React + SVG），逐帧纯函数，任意一帧可单独渲染
- 格式：1920×1080 · 30 fps · 15.00 s · 60 BPM · 带声音（`public/score.wav`）

---

## 一、解读

提示词只给了「青山」「茶叶品牌」「15 秒循环」三件事。其余按水墨的方向补齐：

- **世界**：一张宣纸，青墨一种颜色，唯一的红是印章。
- **情绪**：静、慢、呼吸感。60 BPM，一拍一秒，全片 15 拍。
- **结构**：一滴墨的完整循环 —— 落、成山、化叶、题名、归墨。没有转场，只有同一团墨在变形。
- **推断值**（提示词未给）：分辨率 1920×1080、30 fps、60 BPM、纸色 `#F2EDE1`、墨色 `#1E1C17`、青墨 `#2E3B32`、印泥 `#B0362C`、字体 Songti SC（宋体，印刷中文的骨架），均标 `S##*`。

**全片只出现两个字**：青山。没有标语、没有年份、没有英文 —— 品牌的第一个片头不需要解释。

---

## 二、设计契约

| 项 | 值 |
|---|---|
| 画幅 | 1920×1080，安全区 x±150 / y±90 |
| 纸 | `#F2EDE1` + 细颗粒（0.12）+ 长纤维（0.09），全程不动 |
| 墨 | 一种青墨 `#2E3B32`，只改透明度：远景 0.20 / 中景 0.30 / 近景 0.82 |
| 字 | `#1E1C17`，Songti SC 600，232 px，竖排停在左三分之一 |
| 印 | `#B0362C`，76 px，全片唯一的红 |
| 边缘 | 所有墨块用「纸色渐变 + 湍流扰动」在底部与两端化开，没有一条直边 |
| 山脊 | 脊线上加一道更深的重描 —— 墨在边界积住，这是水痕，不是描边 |
| 运动 | 主要是 `EASE.smooth` 与更慢的 `EASE.inOut`，只有落墨用 `EASE.in` 加速；没有回弹 |
| 转场 | 没有转场：墨块本身在变形，镜头始终不动 |
| 声音 | `ink` 音色：D 低音持续、五声音阶拨弦、水滴、印章木响、笔触沙沙 |

**禁止**：渐变背景、发光、粒子爆发、镜头抖动、emoji、模板式居中标题、超过一个红色元素。

## 三、字幕表与时间轴

| 时间 | 场景 | 观众得到什么 | 承接的物体 | 声音 |
|---|---|---|---|---|
| 0.00–3.20 | 落墨 | 一滴墨从纸上落下，砸出涟漪与墨点 | 种子墨点 | 1.0 水滴 + 低频、1.7 笔触 |
| 3.20–7.00 | 成山 | 墨摊开长成三层山，云在中间 | 同一团墨（山体） | 3.2 / 4.4 / 5.3 拨弦，6.4 笔触 |
| 7.00–10.60 | 一叶 | 近山的脊线被提起来，变成一片茶叶，飘落、收成一滴 | 脊线 → 叶 → 墨珠 | 7.0 / 8.5 拨弦，9.7 收墨声 |
| 10.60–13.40 | 题名 | 墨珠摊开，印出「青山」，印章落下 | 墨珠 → 字 | 10.8 拨弦，11.5 磬，12.5 木响 |
| 13.40–15.00 | 归山 | 墨从字上被抽走，飞回顶端，回到第 0 帧 | 墨珠 → 种子墨点 | 13.4 收声，14.15 水滴 |

逐拍关键帧（60 BPM，一拍 = 1 秒）：

```
0.15 落   1.00 触纸   1.70 洇开   3.20 远山   4.40 中山   5.30 近山
6.40 画脊   7.00 提脊   8.50 成叶   9.60 飘定   9.50 收叶   10.00 墨珠
10.80 摊笔  11.50 显字   12.30 收墨   12.50 钤印   13.40 抽墨   14.15 飞回
14.90 归位（与 0.00 完全一致）
```

## 五、循环

第 0 帧与第 15 秒是同一个状态：纸上只有一个 8 px 的墨点，位置 (1180, 292)，其余全部归零。墨团在 14.90 s 落到种子位置且形状函数与 0.00 s 完全相同（`dropPts(SEED, 8, 0.15)`），所以循环没有接缝。

## 六、运行

```bash
npm install                       # 若 esbuild 需要批准：npm approve-scripts esbuild && npm rebuild esbuild
npm run studio                    # 时间线预览
npm run preview                   # 半分辨率小样 out/preview.mp4
npm run render                    # 导出 out/film.mp4
npm run check                     # 自查（需要 ffmpeg/ffprobe）
```

本机渲染若未自带 Chrome Headless Shell，可指定本机 Chrome：

```bash
npx remotion render Film out/film.mp4 \
  --browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

声音由 `scripts/cues.json` 生成，`npm run render` 前会自动重算 `public/score.wav`。
