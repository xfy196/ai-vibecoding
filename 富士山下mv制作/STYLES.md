## 0. 先读词：这首歌真正的画面是什么

林夕把"失恋"写成了一次**归档**。全片不是"我很痛"，而是"我把你留下的东西一件件清点、命名、封存、归还"。

**情绪曲线**

```
22s 前奏 ── 主歌1（雨 / 外套 / 送她回家）
        ── 副歌1（富士山第一次出现：爱不能私有）
        ── 主歌2（情人节 / 车厢取暖 / 东京）
        ── 副歌2 ── 副歌3（最高点）
        ── 尾声（把陈年风褛还给她，解咒）
```

**歌词直接给出的视觉资产**

| 歌词 | 物件 / 空间 | 能不能拍 |
| --- | --- | --- |
| 拦路雨偏似雪花 | 雨、雪、路灯 | 氛围镜头 |
| 这风褛我给你磨到有襟花 | 一件穿旧的外套，袖口磨破 | 核心道具 |
| 苦心选中今天想车你回家 | 车内、方向盘、后视镜 | 主场景 |
| 花瓣铺满心里坟场 | 花瓣、坟 | 隐喻镜头 |
| 谁能凭爱意要富士山私有 | 富士山 | 片名镜头 |
| 试管里找不到它染污眼眸 | 试管、一滴墨 | 隐喻镜头 |
| 前尘硬化像石头 | 石头 | 核心道具 |
| 忘掉我跟你恩怨 樱花开了几转 | 樱花、年轮 | 转场 |
| 东京之旅一早比一世遥远 | 车票、车站 | 空间反差 |
| 我把这陈年风褛 送赠你解咒 | 归还外套 | 结尾 |

**共同的关键词**：私有 / 归还 / 封存 / 温度 / 一层玻璃。

四个方向都建立在这五个词上，只是"用什么材质去承载"不同。

## A · 雪夜胶片（35mm 车内雨夜）

**概念**：整支 MV 是**最后一程车**。从她上车到下车，镜头不出车厢，观众始终隔着一层起雾的玻璃看她。

**画面语言**

- 1.85:1 画幅，上下留黑边，边角打片号 / 时间码，像一卷洗出来的胶片
- 35mm 颗粒 + 轻微漏光 + 高光halation，钠灯橙（#FFB35C）与冷青（#7FC8FF）对冲
- 全程浅景深，对焦点永远在"玻璃上的水"而不是人
- 机位基本不动：副驾视角、后视镜、方向盘、雨刷扫过的一秒黑

**适合段落**：主歌 1（送她回家）、主歌 2（车厢取暖）、尾声（她下车）

**关键镜头**

| 时间 | 歌词 | 画面 |
| --- | --- | --- |
| 0:21 | 拦路雨偏似雪花 | 挡风玻璃，雨点被路灯照成雪 |
| 0:26 | 这风褛我给你磨到有襟花 | 后视镜里她搭在腿上的旧外套，袖口起球 |
| 0:35 | 苦心选中今天想车你回家 | 雨刷扫过一次，露出半秒清晰的路牌 |
| 1:17 | 谁能凭爱意要富士山私有 | 玻璃上哈气，用手指画一座山，又抹掉 |
| 1:51 | 留在汽车里取暖 | 暖风出风口，纸巾上凝结的水汽 |
| 3:52 | 我把这陈年风褛 送赠你解咒 | 外套留在副驾座，车门关上，车内空镜 |

**制作**：中高。需要大量"照片级"画面，纯代码绘制难度大，建议 AI 生图 + 局部图层动画（雨、光斑、雨刷、呼吸雾），逐帧合成。工期约 2–3 天。

**风险**：最容易"像"，也最容易"假"。水滴、皮肤、车漆任何一处不对就掉档。

## B · 纸艺立体书（剪纸叠层 · 立体书页）

**概念**：这是一本**她留下的立体书**。每唱一句，翻一页，纸做的富士山从书脊上弹起来；唱完，合上书，压平。

**画面语言**

- 暖米色纸（#EFE2CC）+ 牛皮纸阴影，所有元素都有 2–4mm 的纸厚和投影
- 一切用"剪"和"折"完成：山是叠起来的纸片，人是两片纸，雪是撕出来的毛边
- 中缝一条折痕贯穿全片，翻页时整页纸会轻微拱起
- 红色印章「富士山下」「私有」「解咒」，每段盖一次

**适合段落**：全片（尤其副歌——山弹起来的那一下）

**关键镜头**

| 时间 | 歌词 | 画面 |
| --- | --- | --- |
| 0:22 | 拦路雨偏似雪花 | 书页翻开，纸做的雨丝从页缝里立起来 |
| 0:26 | 这风褛我给你磨到有襟花 | 纸外套挂在纸钩上，襟花是磨破的一个小洞 |
| 1:12 | 谁能凭爱意要富士山私有 | 富士山整页弹起，太阳是贴上去的红圆片 |
| 1:26 | 前尘硬化像石头 | 石头是一块厚卡纸，落地时有重量感 |
| 2:10 | 樱花开了几转 | 纸屑花瓣从书页间洒下，翻转着落 |
| 3:52 | 送赠你解咒 | 外套被剪下来，装进一个纸信封，合书 |

**制作**：低。纯 Canvas/SVG 矢量绘制，可程序化生成，逐帧确定性渲染。本仓库有现成模板（参考 `../cishibuhuan-mv`），工期约 1 天。

**风险**：纸艺天生偏"可爱"，需要用低饱和的蓝灰 + 大留白 + 慢镜头把情绪拉回成年人。

## C · 水墨水彩（宣纸 · 墨分五色）

**概念**：全片是**一幅画被画出来又毁掉**的过程。开场只有一张宣纸，笔一笔一笔把山画出来；副歌最高点，一滴墨落进水里，把山化开。

**画面语言**

- 生宣质感：纤维、水痕、边缘的墨洇
- 墨分五色：焦、浓、重、淡、清；唯一的彩色是朱砂（花瓣、印章）
- 竖排题字从右往左落，字是"写"上去的，不是"打"上去的
- 留白占 60% 以上，山只占画面三分之一

**适合段落**：副歌（三次副歌 = 三次"画山 / 山被抹掉"）、前奏

**关键镜头**

| 时间 | 歌词 | 画面 |
| --- | --- | --- |
| 0:22 | 拦路雨偏似雪花 | 空白宣纸，第一滴墨落下，晕成雪 |
| 1:12 | 谁能凭爱意要富士山私有 | 山画成，题字落下，朱砂印章盖在"私有"上 |
| 1:21 | 试管里找不到它染污眼眸 | 试管里一滴墨慢慢散开，染黑整管水 |
| 2:47 | 前尘硬化像石头 | 墨迹干成一块石头，边缘发硬、开裂 |
| 3:46 | 我便化乌有 | 整座山被一笔水抹开，只剩一道淡影 |
| 3:52 | 送赠你解咒 | 落款，收笔，纸卷起 |

**制作**：中。静态构图省力，难点在"笔触"——需要噪声位移 + 遮罩生长的程序化笔刷，或逐帧手绘关键笔触再插值。工期约 2 天。

**风险**：容易滑向"国风壁纸"，必须有具体的人和物（一件外套、一双手）把叙事钉住。

## D · 证物档案（俯拍 flat-lay · 物证标签）

**概念**：分手之后，把这六件东西装进证物袋，编上号，写进卷宗。标题叫「解咒」，结论是：**申请"私有"——驳回**。

**画面语言**

- 全程 90° 俯拍一张牛皮档案纸，网格、打孔、编号、手写批注
- 六件物证：001 风褛 / 002 车票 / 003 花瓣 / 004 石头 / 005 试管 / 006 钥匙
- 打字机字体 + 中文宋体，红色双圈章「私有 · DENIED」
- 镜头只做推、移、轻微旋转；每次"揭示"新物证就有一声纸的摩擦

**适合段落**：全片。副歌时把物证一件件推到画面中央，主歌时静止

**关键镜头**

| 时间 | 歌词 | 画面 |
| --- | --- | --- |
| 0:22 | 拦路雨偏似雪花 | 空档案纸，打字机一个字一个字打出"CASE 001" |
| 0:26 | 这风褛我给你磨到有襟花 | 001 号证物袋推入，外套袖口的破洞被红圈标出 |
| 0:58 | 谁都只得那双手 | 六件物证同时入画，红线把它们串起来 |
| 1:12 | 谁能凭爱意要富士山私有 | 章落下，「私有 / DENIED」，墨没干 |
| 1:26 | 前尘硬化像石头 | 004 石头被翻过来，底面刻着日期 |
| 2:14 | 东京之旅一早比一世遥远 | 两张同日同车次的车票，一张没检票 |
| 3:52 | 我把这陈年风褛 送赠你解咒 | 001 号袋被划开，外套取出，所有标签脱落 |

**制作**：低—中。静态素材多，动画靠运镜、纸的位移和文字逐字出现；最省算力，但最考美术。工期约 1 天。

**风险**：太冷。需要在某一刻出现一只手（把物证摆正、盖章、撕开袋子），全片才有体温。

## 我的建议

**首选 D（证物档案）**，理由三条：

1. **最贴歌词**。整首歌就是在清点遗物，"编号 / 驳回 / 归还"这套语言几乎是为它写的；
2. **最好做**。90% 是静态构图 + 运镜，程序化渲染最稳，一天能出成片，改起来也快；
3. **最有辨识度**。市面上《富士山下》的 MV 二创基本是实拍或国风，档案体没人做过。

**如果想要更"电影"**：选 A，但要接受 2–3 天和 AI 生图的品控成本。
**如果想要更"好看好传播"**：选 C，水墨封面天然适合当短视频首图。

也可以**混搭**：主骨架用 D，三次副歌的"富士山"镜头切进 C 的水墨空镜，冷档案里插三段会呼吸的画——代价是多一套素材管线。

## 下一步

选定方向后，工程按这个顺序推进：

1. 定风格 → 改 `data/spec.json` 的分镜与配色
2. 画关键帧（3–5 张）确认质感 → `node scripts/keyart.mjs`
3. 出 4–6 个静止帧预检 → `node scripts/render.mjs --stills`
4. 全片逐帧渲染 → `node scripts/render.mjs`（约 7260 帧）
5. 合原曲 → `node scripts/mux.mjs reference/song.mp3`
