# 《忘记时间》MV — 小人主镜头版 · 完整提示词手册

> 用途：每个镜头一段可直接喂 AI 视频模型（可灵 / 即梦 / Veo / Sora）的提示词，
> 后面跟一行「HyperFrames 实现要点」，把同一镜头交回 code agent 重建也能用。
> 结构：诊断 → 三条硬规则 → 可粘的风格锚与负面词 → 角色卡 → 词表 → 34 镜提示词 → 流水线。

---

## 1. 上一版为什么僵（先看清病，再吃药）

我把已经生成的工程翻出来数了一遍，僵不是感觉，是七个可以点出来的事实：

1. **画面里没有「人」，只有物的界面。** 33 处人物精灵分布在 10 场里，开场 12.4 秒
   **一个人都没有**（纯显示器 POV）。终端、游戏窗口、照片、波形、进度条轮流出镜，
   人只是坐在画面边缘的背影。观众跟着界面走，不跟着人走 → 像说明片，不像 MV。
2. **只有「景动」，没有「人演」。** 走廊那场人物固定在 x=150 不动，背景往左滑动；
   窗外云在动、雨在动、指针在转，人物是贴图。人一旦不动，MV 就变成会动的壁纸。
3. **动作只有两种状态：站、走。** hero-walk 4 帧、hero-idle 2 帧、猫 2 帧、
   她的笑只有 1 帧。没有呼吸、没有反应、没有表情变化，所以「他在写代码」这件事
   从头到尾没有表演，只有姿势。
4. **动效曲线是一条直线。** 全片 77 个 tween 用 `steps()` 线性推进，只有 8 个用了真曲线。
   线性 = 机器人平移。缺三样东西：**预备（抬手前先缩一下）、跟随（停下后多走 2 帧）、
   停顿（落地后 6–12 帧不动）**。
5. **只有一个平面。** 除走廊一点视差，人物和背景贴在同一层，没有前景遮挡、没有推镜头、
   没有过肩。所以画面「贴纸感」重，观众的眼睛没有纵深可走。
6. **节拍没进画面。** 切点全部落在歌词行（7–8 秒一镜），副歌没有加密到半拍。
   130.4 bpm（0.46 秒一拍）这个数字只写在分析文件里，没有进剪辑。
7. **没有反应镜头。** 全片没有一次「他看屏幕 → 屏幕给他一个反应」的正反打。
   没有视线，就没有代入。

**结论**：不是像素风不好看，是**分镜的主语错了**——上一版的主语是「作品」，你要的主语是「他」。

## 2. 三条硬规则（照这个拍就不会僵）

**规则 A：每一镜都以人的身体开场。**
开场元素必须是手、眼、肩、背、下巴、呼吸里的一种；房间、屏幕、雨永远只是他身后的东西。
唯一例外：S31 之后允许空镜（人已经不在镜头里，因为故事讲完了）。

**规则 B：每一镜必须有「一个动作 + 一个停顿」。**
动作分三段：预备（3–5 帧的反向小动作）→ 发力（2–4 帧）→ 停顿（6–12 帧完全静止）。
AI 视频模型最擅长做这个，因为它把「静止」当成难度低的帧；我们的上一版恰好完全没有停顿。

**规则 C：每一章至少一个反应镜头。**
结构固定为：**他做了什么 → 屏幕上出现什么 → 他的脸怎么变**。
副歌（1:30 / 2:59）把这个结构压到 4 秒一组，形成正反打节奏。

## 3. 可粘块 ①：STYLE（每段提示词的最前面都粘这一行）

```
像素艺术动画（pixel art animation），16 色限制调色板，硬边、无抗锯齿、无平滑渐变；
画面按 480×270 网格绘制后放大 4 倍（每个像素格清晰可见），16:9，横向构图；
轻微 CRT 扫描线与极淡的暗角；调色板——夜色 #070613 / #1c1740 / #312868，
暖光 #ffc96b / #ff9440 / #d64f2b，终端绿松 #69f0d2 / #23b39a，
情绪粉 #ff77b0 / #c8417c，纸白 #f7f2e2；光源只有两种：屏幕的冷光、台灯/路灯的暖光。
```

## 4. 可粘块 ②：NEG（负面词，每次生成都带上）

```
不要：真实照片质感、3D 渲染、写实皮肤与五官、光滑渐变、景深虚化、镜头光晕、辉光溢出、
动态模糊、粒子特效爆炸、烟雾体积光、抖动故障滤镜、快速白闪；
不要在画面里生成任何文字、字幕、水印、按钮、UI 截图、logo；
不要人物僵硬直立不动、不要正面海报式对称构图、不要两人同时看镜头；
不要二次元厚涂、不要赛璐璐描边、不要 4:3 或竖构图。
```

## 5. 角色卡（每次生成都用同一段字描述，别改词）

### A · 他（主角，全片 80% 的镜头）
```
像素小人，身高约 22 个像素格，头身比 1:3.2，略瘦；深紫连帽衫（#5a49a8，帽子内侧 #312868），
深蓝黑短发（#2a2347），肤色 #f2c9a1，深色直筒裤（#171436），白球鞋（#e8e2d0），
左耳挂一只绿色耳机线（#69f0d2）。侧脸有一点没刮干净的胡茬（两格深色像素）。
```
**动作集（8 个，按需调用）**：打字（左右手交替 2 帧）、搓手、揉眼、往后靠、
抓头发、端杯喝一口、低头看键盘、缓慢眨眼。
**表情集（5 个）**：专注（眉压低）、放空（眼神偏上）、笑（嘴角 1 格）、垮（嘴角垂 1 格）、
闭眼（2 格横线）。

### B · 她（只存在于屏幕/记忆里）
```
像素小人，身高约 21 格，玫红长发（#b03a6e）垂到腰，淡紫长裙（#8d7fd0），纸白裙边（#ded7c4），
皮肤 #f2c9a1，白球鞋。只有三个状态可用：撑伞站着等、转身、笑（笑是最重要的一个，只给 3 次）。
```
**她永远不和他同框，只有一个例外**：S12（84–90.8s）的暖色记忆镜头，允许两人同框一次。

### C · 猫（只在 S23、S34 出现）
```
像素猫，12×8 格，深灰紫（#312868）底，尾尖一撮粉（#ff77b0），两条白胡须各 1 格；
只做一件事：跳上桌，原地转半圈，趴下。
```

### 一致性五条（这五条比提示词本身重要）
1. 每次生成都把角色卡那段原文完整粘进去，**一个字都不要改**——模型靠重复锚定外观。
2. 先用文生图出**同一个角色的三视图 + 三个表情**，存成参考图；之后每个镜头都用图生视频。
3. 同一镜头一次出 3 条，只留动作最接近「预备→发力→停顿」的那条。
4. 每段生成控制在 **5–8 秒**，超过 8 秒的动作模型会开始漂（详见 §8 流水线）。
5. 生成时别让角色写字、别让角色读字幕——像素小人一旦要「演文字」，脸就崩。

## 6. 可粘块 ③：词表（拼提示词用，别自己造词）

**景别**：大远景（人物只占画面 1/10）、全景（全身入画）、中景（腰以上）、
近景（胸以上）、特写（头）、大特写（只有眼睛/手）、过肩、俯拍、仰拍、侧后方跟拍。

**运镜**（像素风只做「整格平移」，不做平滑滑动）：
缓慢推近（每 2 秒放 1%）、缓慢拉远、横移跟拍、摇上、甩镜（1 帧切换方向）、
俯冲下潜（往屏幕里钻）、原地轻晃（手持感，幅度 2 像素）。

**动作节奏词**：先缩一下再伸手、抬手到一半停住、按下后手指停在键上两拍、
整个人往后一沉、肩膀先动、膝盖弯下去再撑起来。

**光线**：屏幕冷光从下往上打脸、台灯暖光从左后方、路灯在雨里的一小圈暖光、
天亮时从窗口斜切进来的一条光、只靠屏幕照明的暗脸（半张脸在暗部）。

**情绪**：专注到忘了时间、忽然意识到什么、说不出口、撑着、放弃一半又捡起来、
笑了一下又收回去、终于松了一口气。

## 7. 分镜提示词（34 镜）

> 每镜格式：**时间 · 歌词行** ／ 镜位 · 动作 ／ 提示词（= STYLE + 这段 + NEG）／ HyperFrames 实现要点。
> 时长都控制在 5–12 秒；超过 8 秒的镜头在 §8 里写了怎么用「延长」补齐。

### 第一章（0:00–0:32.07）他还没睡

**S01 · 0:00–0:06.0（前奏未起）**
镜位：大特写 · 侧面 · 极慢推 ｜ 动作：眨一次眼 → 停 → 屏幕的光在瞳孔里刷新一次
```
大特写：一个像素小人男的侧脸占满画面右三分之二，左三分之一留给身后显示器的冷光。
他戴着单边绿色耳机线，深紫连帽衫的帽子堆在脖子上。画面几乎全暗，只有屏幕的冷绿白光
从右下方低角度打在他的颧骨、睫毛和下巴上，左半张脸沉在暗部。
动作：他缓慢地眨一次眼（上眼睑降两格像素，停两帧，再抬回），然后完全静止，
瞳孔里的绿白色像素块每隔半秒刷新一次。机位以每两秒 1% 的速度极缓慢推近。
空气里只有一点极淡的浮尘。情绪：专注到忘了自己还在呼吸。
```
HF：`#root` 里放一张 3/4 侧脸精灵（12×18 格）+ 瞳孔里 2×2 的刷新块；相机 `scale 1.00→1.06`，`ease:"steps(30)"`，6 秒；眨眼用 3 帧精灵在 1.2s 处切换，之后 4.8 秒不动。

**S02 · 0:06–0:12.4（第一个音进来）**
镜位：大特写 · 手部 · 从手腕推到指尖 ｜ 动作：抬手到一半停住 → 落下敲一下 → 手指停在键上两拍
```
大特写：像素小人的双手放在深色键盘上，画面从左下角斜切进他的手背和指节。
冷绿白色的屏幕光从上方打下来，把他的手指边缘照出一圈一格宽的亮边；
右侧有一缕咖啡的热气从画面外飘进来，掠过手背。
动作：右手抬起，抬到一半时停住（两拍），然后落下，食指敲下一个键——键盘底下一格
绿光同时亮起；敲完手指停在键上不动，只有热气在动。
机位从手腕缓慢推到指尖，幅度很小。
```
HF：手部精灵 4 帧（抬/停/落/停）；按键时在按键位置 `set` 一格 `#69f0d2` 再下一拍关掉；热气 3 格像素 `steps(4)` 上飘 20px 循环 3 次。

**S03 · 0:12.4–0:20.0（段落 B）**
镜位：全景 → 拉远成中远景 ｜ 动作：他坐着，椅子被脚一蹬转了半圈，他伸手扶住桌沿稳住
```
全景：一个像素小人男背对镜头坐在书桌前，屋子只有一盏台灯光（暖琥珀 #ffc96b）
从左上角和一块显示器的冷光（#69f0d2）从他身前打过来，两种光在他的背上交界。
右侧有一扇窗，窗外是深蓝夜色和一弯月，窗台上一只杯子冒着一点热气。
动作：他用脚一蹬地面，办公椅缓慢转了半圈，然后他伸手扶住桌沿把椅子稳住——
肩膀先动，手后到。全屋的粒子（热气、浮尘）都在动，只有他扶住之后停了。
机位在 7 秒内从全景缓慢拉远，露出更多空着的房间。
```
HF：房间静态图 + 椅子精灵单独一层做 `rotation 0→-160` 再 `set`；他扶桌沿是 3 帧手臂精灵；相机 `scale 1.12→1.00`。

**S04 · 0:20.0–0:32.07（段落 C，标题进来）**
镜位：侧面中景 → 过肩 ｜ 动作：打字（肩起伏）→ 停手 → 抬头看一眼屏幕 → 又低下头
```
侧面中景：同一个像素小人男，侧身坐在桌前打字，只看得见他的侧脸、肩膀和手臂。
屏幕的光随屏幕内容变化：先是清冷的青绿，然后慢慢变成偏暖的琥珀色，光从他脸上扫过。
动作：他打了四拍字（肩膀跟着起伏），然后停下来，微微抬头看一眼屏幕（下巴抬起两格），
再低下头，右手回到键盘上。停了整整两拍才继续。
机位在中景保持不动，只做极轻微的横向漂移（2 像素），像有人端着机器看。
```
HF：打字 2 帧交替 6fps（=一拍 3 帧，正好落在 130bpm 上）；屏幕光变色用一个覆盖他的 `background:radial-gradient` 层从青换到琥珀（`opacity` 换层，不改色值）；抬头是 `y:-2` 2 帧到位再停。

**S05 · 0:32.07–0:40.14（沉默着 走了有 多遥远）**
镜位：侧后方跟拍 ｜ 动作：他端着杯子往前走 → 走三步 → 停下 → 杯子里的水晃一下
```
侧后方跟拍：像素小人男端着杯子在一条长长的走廊里往前走，镜头贴在他右后方跟着他。
走廊两侧是深色的墙和零星的门，地面反着一点冷光；他身后飘着一串细小的发光像素块
（像浮起来的代码行），被他走过时搅动。
动作：他走三步，第三步落地时停住（多停一拍），杯里的水面晃了一下才平。
机位跟着他平移，节奏是「走—停—再走」，不是匀速滑轨。
```
HF：走廊分三层视差（墙 / 门 / 地面）分别在 `x` 上以 0.6/1.0/1.4 倍速度平移；人物 4 帧走路循环 4fps；像素块一串用 `stagger` 跟随。

**S06 · 0:40.14–0:46.98（抬起头 蓦然间 才发现）**
镜位：仰拍 · 后背 → 摇上到天花板 ｜ 动作：他停下、抬头（先抬下巴，再抬眼睛）→ 定住
```
仰拍：像素小人男站在走廊中央，镜头从他脖子后面往上仰。他慢慢抬起头——
先抬下巴，两拍后眼睛才往上，然后整个人定住。
随着他抬头，镜头上摇，露出天花板：那不是天花板，是一整片深蓝色的夜空，
上面浮着成百上千个细小的发光像素块（文件、星点、代码行），缓慢地漂。
他的后脑是一个暗色的剪影，压在下三分之一。
```
HF：人物后背精灵固定，只做 `head` 那格 `y` 变化；镜头上摇用整层 `y:+180` `steps(18)`；星点 40 个 `opacity` 分 3 组闪烁（有限 repeat）。

**S07 · 0:46.98–0:54.73（一直倒退 倒退到原点）**
镜位：侧后方跟拍（反向）｜ 动作：他倒着走回去（脚是倒放的）→ 像素块逆流
```
侧后方跟拍，但是倒放：像素小人男在走廊里倒退着走，脚步是反着来的（先落脚跟再离地），
他身后的发光像素块全部逆着方向流回去，走廊两侧的门一盏一盏地「关回去」。
他的表情是空白的，眼睛不看前面，只盯着脚下。
机位逆向平移，速度比 S05 快一倍，像录像带在倒。
```
HF：把 S05 的走廊层 `x` 反向 tween，速度 2×；人物用镜像 + 4 帧倒序播放；门用 `opacity` 反向阶梯。

**S08 · 0:54.73–1:02.44（倔强坚持 对抗时间）**
镜位：侧面全身 · 低机位 ｜ 动作：双手推巨大的指针 → 指针压下来 → 膝盖弯下去 → 又撑起来
```
侧面全身、低机位：画面里有一面巨大的像素钟表，钟面占了画面右上三分之二，
指针粗得像一根梁。像素小人男站在钟前，双手撑在那根正在往下压的指针上。
动作：指针往下压（一格一格地压），他的膝盖弯下去、背弓起来，撑了两拍，
然后腿一蹬，把指针推回去一点——指针往上走一格，又立刻开始往下压。
他的白球鞋在地上蹭出一小段痕迹。机位很低，几乎贴着地面。
```
HF：钟面是程序化生成的实心像素圆（按行画），指针是两条 `transform-origin:50% 100%` 的长条，用 `rotation steps(60)`；人物三态（撑住/弯下/撑起）各 2 帧，按指针角度切换。

### 第二章（1:02.44–1:30.83）断了

**S09 · 1:02.44–1:10.00（说好了 的永远 断了线）**
镜位：中近景 · 过肩 ｜ 动作：他看着屏幕上断开的线 → 手从键盘抬起 → 又慢慢放下
```
中近景过肩：越过像素小人男的右肩看屏幕，屏幕上有一条横贯的细线，线中间断开了一小截。
他的侧脸在画面左侧，只有屏幕的光。
动作：他盯着那条断线看了两拍，右手离开键盘抬起来（抬到胸前停住），
然后慢慢地放回桌面，手掌摊平。肩膀塌下去一格。
```
HF：屏幕内容单独一层；手用 4 帧（停/抬/停/落）；肩膀塌下是躯干 1 格位移 + 停 3 拍。

**S10 · 1:10.00–1:16.56（期许了不变的 却都已改变）**
镜位：大特写 · 眼睛 ｜ 动作：眨眼 → 瞳孔里画面变 → 眼睛睁大一点
```
大特写：像素小人男的一只眼睛占满画面，睫毛是一行深色像素。
瞳孔里映着屏幕上的画面：一颗像素心形慢慢裂成两半（只在他瞳孔里看得见，很小）。
动作：他眨一次眼，睁眼时瞳孔里的心已经裂开了；他眼睛睁大一点（上眼睑再抬一格），
```

## 8. 节奏与生成流水线

### 8.1 把节拍放进来（上一版最大的漏洞）
- 曲速 **130.4 bpm**，一拍 = **0.46s**，4 拍一小节 = **1.84s**，8 拍 = 3.68s。
- 歌词行是切点（见每一镜的时间）；**副歌（1:30–2:01、2:59–3:29）在每行歌词内部再对半切一次**，
  即每 2–4 秒一个硬切，切在同一镜位的两个不同动作之间（例：S15 里「脸塌成棋盘格」之后半拍插「手停在半空」）。
- 所有「落下/按下/敲」的动作，落点对齐拍点；所有「停顿」至少一拍（0.46s），悲的地方给两拍（0.92s）。
- 走路 4 帧 = 一拍一个循环（≈ 8.7 帧/秒），**不要**用 4.5 或 9 fps 这种和音乐无关的数字。

### 8.2 生成流水线（每个镜头都走一遍）
1. **角色定妆**：先用文生图出「他」的三视图 + 五个表情各一张，存成参考图。这一步做不好，后面 34 个镜头都会漂。
2. **首帧定格**：用 §7 的提示词做**图片生成**，直到第一帧的构图、光位、人物比例都对——首帧错，视频必错。
3. **图生视频**：把首帧 + 同一段提示词（再补一句"以首帧为起点，动作按描述发生，机位按描述移动"）喂给视频模型，
   时长设 5 秒；需要更长的镜头用「延长」接第二段，接的时候保持「上一条的最后一帧 = 下一条的第一帧」。
4. **每次出 3 条**，只留动作最像「预备→发力→停顿」的那条。
5. **对齐歌词**：在剪辑里先把音轨铺好，把每个镜头放在 §7 写的时间上，再微调 ±0.1s 找手感。
6. **整片过一遍**：任意一个镜头里如果人物超过 2 秒完全没动作、也没光在动 → 回去补一个停顿之外的小动作。

### 8.3 自检清单（拍完逐条打勾）
- [ ] 每一镜的第一个可见元素是人的身体（手/眼/肩/背），不是房间或屏幕？
- [ ] 每一镜都有「一个动作 + 一次停顿」，停顿有人数得出来吗？
- [ ] 每一章都有至少一个「他看屏幕 → 屏幕给他反应 → 他的脸变了」的正反打？
- [ ] 副歌是 2–4 秒一切，主歌是 6–8 秒一切（节奏差能听出来）？
- [ ] 他和她同框的次数 = 1（S12）？她的笑出现 = 3 次（S12 / S27 / S30）？
- [ ] 画面里没有一个可以在屏幕上念出来的字？
- [ ] 片尾那个像素点熄灭之后，还剩几帧黑？（建议 1–2 秒，别拖 4 秒）
