# SPEC — 《忘记时间》× VIBECODING（小人主镜头版 / v2）

4:32（272.11 s）｜1920×1080 ｜30 fps ｜逻辑像素 480×270 ×4（U = 4px）｜Zpix 12px 像素字
｜16 色限制调色板｜一条音轨（原曲，无音效无旁白）

## 一个故事

一个像素开发者在一夜之间，用 vibecoding 做出一个关于「她」的小站台游戏。
写、生成、跑崩、修、上线、天亮。她只活在他做出来的那块屏幕里。

## v2 相对 v1 改了什么（僵 → 演）

| v1 | v2 |
| --- | --- |
| 开场 12.4 秒没有人物，纯显示器视角 | 开场是**他的侧脸大特写**（S01）+ 手部落键（S02） |
| 只有站、走两态 | 新增可表演的脸（睁/半闭/闭/嘴型/眉）与手（抬→悬停→落→停住），相机参与表演 |
| 77 个 tween 几乎全是线性推进 | 每个动作三段：预备 → 发力 → 停顿（0.46 s 起） |
| 一个平面，人贴着背景 | 每个场景 3 层视差 + 前景遮挡 + 推拉机位（`cam()` 包一个人全身的相机层） |
| 切点只跟歌词行 | 副歌仍是 2–4 s 一切，但切在同一镜位的两个不同动作之间 |
| 没有反应镜头 | 每章至少一次「他看屏幕 → 屏幕给他反应 → 他的脸变了」的正反打 |
| 歌词 34 行全上屏（72px） | 只保留歌词主线，远景 72px、贴着人脸时 48px 落到最下沿 |

## 三条表演规则（写代码时也要守）

1. **每一镜以人的身体开场**：手、眼、肩、背、下巴，房间和屏幕只是他身后的东西。
2. **一个动作 + 一次停顿**：预备（3–5 帧反向小动作）→ 发力（2–4 帧）→ 停顿（一拍 0.46 s 起）。
3. **每章至少一个反应镜头**：他做了什么 → 屏幕出现什么 → 他的脸怎么变。

## 技术

- `build/kit.mjs`：`face()`（3/4 侧脸，28×24 像素，眼/眉/嘴可单独换）、`hand()`（食指可抬起落下 + 键位亮光）、
  `laptop()`（盖子绕后缘合上）、`chair()`、`girlBack()`、`clockFace()`、`camLayer()`、`layer()`，
  以及时间轴助手 `cam/camTo/vis/swap/cycleBg/blink/lyricIn`（全部有限 repeat，可逐帧寻址）。
- 节拍：130.4 bpm，一拍 0.46 s；走路 4 帧 = 一拍（8.7 fps），按压/落下对齐拍点，停顿至少一拍。
- 全片静态 HTML + GSAP 暂停时间轴；GSAP 已本地化（`assets/vendor/gsap.min.js`），无网络请求、无随机数。
