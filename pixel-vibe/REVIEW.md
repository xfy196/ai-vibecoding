# REVIEW — 《忘记时间》× VIBECODING（v2，小人主镜头版）

## 这一版做了什么

按 `MV-PROMPTS.md` 重剪：34 个镜头，主语从「界面」换成「他」。
开场不再是显示器，是他的侧脸大特写（瞳孔里屏幕光每半秒刷新一次），第二镜是手部落键：
抬到一半停住 → 落下 → 停在键上。全片新增三样东西——**可表演的脸和手**、**相机**、**停顿**。

- 台词/歌词：34 行只留主线；远景 72px，贴着人脸时 48px 落到最下沿，不抢脸。
- 同框仍只有一次（S12 暖色站台）；她的笑出现三次（S12 / S27 / S30）。
- 片尾：合上笔记本 → 晨光爬上地板 → 城市剪影 → 一路拉远收成一个熄灭的像素点。

## 测过的（数字）

- `hyperframes check --json`：lint / runtime / layout / motion / contrast / audio **全 0 error、0 warning**（v1 有 1 条行数警告，v2 拆得更细）。
- 成片：1920×1080 / 30 fps / 272.13 s / 21.2 MB / H.264 + AAC 48 kHz 立体声。
- 响度 **-14.5 LUFS**（integrated），True peak **-2.2 dBFS**。
- 抽帧核对（成片直接抽的帧）：每个镜头都有内容，无空帧；三处 48px 小歌词在 y≈915–990 的带里都能数到 7.7k–27k 个亮像素；
  271.86 s 只剩一个像素点。
- 修掉的一处硬伤：v2 第一版里 S32（合上笔记本）后 10 秒几乎全黑（mean 7.7 / max 63）。
  改为给这间屋子加一扇窗、并把晨光从 6 秒开始缓慢透进来（现在 mean 12–14 / max 96），暗场仍有光在动。

## 没测过

- **声音没有被听过**，只被测量过。
- **没有人类眼睛看过成片**。我用的是数字核对 + 把关键帧压成 76×25 的亮度图看构图（确认脸填满画幅、
  没有元素飞出画面、歌词与脸不打架）。「像不像、好不好看」这一层还得你看。

## 最弱的两处（下一轮优先改）

1. **S08（54.7–62.4s）对抗时间**：他撑指针靠的是整体位移 + 微旋转，没有真正的手部接触点。
   应该让手和指针在同一帧接触，指针压下来时手的像素被压住。
2. **S33（4:00–4:15s）睡着**：只有「光在爬 + 两帧呼吸」，15 秒偏长。
   可以加一个猫跳上膝头、或让他的头慢慢歪下去再停住。

## 有意保留的

- 像素风里所有运动仍是 `steps()` 量化（这是风格，不是偷懒）：但每个动作都补了预备帧和停顿帧，
  走路循环从「和音乐无关的 4.5/9 fps」统一成**一拍 0.46 s 一个循环**。
- 场景文件偏长（s05 单文件 394 行）：一场戏一条站台，拆开就要复制六遍画法，保留整场更好改。
