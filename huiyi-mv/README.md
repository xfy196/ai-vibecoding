# 把回忆拼好给你 · 立体书 MV（前 60 秒）

16:9 / 1920×1080 / 30fps / 60.00s

## 管线

1. **音频分析** `scripts/analyze.mjs`
   - 用 ffmpeg 把原曲前 70 秒解码成 22.05kHz 单声道 PCM
   - 计算 RMS 包络、低频（鼓）包络、自相关测 BPM、能量低谷定位乐句
   - 输出 `audio/analysis.json`（BPM 105.5，首拍 0.39s，节拍间隔 0.5687s）

2. **分镜与歌词** `data/spec.json` / `data/lyrics.lrc`
   - 18 句歌词 → 18 个纸艺场景，每句一个关键词
   - 场景切换与歌词起唱点对齐，道具弹动对齐 0.5687s 的鼓点网格

3. **绘制** `public/js/`
   - `props.js` 纸片道具库（剪纸描边 + 柔投影 + 水彩晕染 + Q 版纸片人）
   - `scenes.js` / `scenes2.js` 18 个分镜 + 顶部纸挂饰（跟鼓点弹）
   - `core.js` 教室背景、课桌、立体书、镜头推近、翻页转场、歌词盖章、合书成礼
   - p5.js 画布，`window.renderFrame(t)` 按时间**确定性**绘制单帧（不用动画循环）

4. **逐帧渲染** `scripts/render.mjs`
   - Node 起本地静态服务器 → puppeteer-core 调本机 Chrome 无头模式
   - 1800 帧逐帧调用 `renderFrame(i/30)`，取 canvas JPEG 写入 `out/frames/`

5. **合片** `scripts/mux.mjs`
   - ffmpeg 截取原曲 0–60s（首尾轻微淡入淡出）→ libx264 CRF17 + AAC 224k

## 运行

```bash
node scripts/analyze.mjs          # 可选：重新分析节拍
node scripts/render.mjs --stills  # 预览若干关键帧 → out/stills/
node scripts/render.mjs           # 全片 1800 帧 → out/frames/
node scripts/mux.mjs              # 出片 → out/把回忆拼好给你_立体书MV_60s.mp4
```
