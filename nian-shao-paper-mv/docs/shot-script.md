## 0. 一句话概念

**把一首关于"来不及"的歌，做成一叠被反复翻动、撕开又粘回去的纸。**

整支 MV 是一张桌面上的剪纸立体书（paper diorama）：所有画面都由硬边纸片叠成，片与片之间是真实纸层硬投影，没有一张照片、没有一个素材。镜头在纸层之间穿行，段落之间用"纸张的动作"（滑动、撕开、翻页、压印）完成转场。

情绪弧线：**冷蓝的夜 → 灰的温度 → 金的机会 → 雨的空洞 → 暖的家（假想）→ 升起的美梦 → 红的婚礼 → 黑与一张纸。**

## 2. 视觉系统：层叠剪纸（Layered Paper-Cut）

### 2.1 纸层规则（每个镜头都遵守，保证"同一叠纸"）

1. **景深分层 6 层**：①背景纸（渐变+纸纹）②远景剪影 ③中景主体 ④近景遮挡 ⑤前景散件（纸屑/雨条/光斑）⑥全局纸颗粒 + 暗角。
2. **硬投影，不虚焦**：每层用同一轮廓的偏移副本作阴影（`translate(0, 11~22px)` + 22–34% 黑），模拟硬光源下的纸立体书；不用 `feDropShadow`（慢且糊）。
3. **剪纸边缘三件套**：
   - **毛边/破口**（deckle）：轮廓用低频噪声扰动，模拟手剪的微抖；
   - **锯齿纹**（锯齿 3–6 px 尖角，出现在轮廓的一侧）；
   - **月牙纹 / 云纹 / 铜钱纹**：镂空的负形装饰（`fill-rule: evenodd` 挖洞），只在"装饰层"使用。
4. **动的都是纸**：所有运动都必须解释为纸的动作——滑入、抬起、翻面、被吹动、被撕、被压印。禁止"物体自己变形"。
5. **相机是手**：虚拟相机永远是缓慢推/摇/移（0.5–2 %/s），并在换气点轻微抖动；不允许快速甩镜（除一次刻意的"砸墙"冲击）。
6. **纸纹统一**：`tex/grain.png`（全屏颗粒，overlay）+ `tex/fiber.png`（纤维，横向纹理）+ `tex/blotch.png`（大张纸的不均匀），三张均由 FFT 周期噪声生成，可无缝平铺。

### 2.2 声音层

- **纸的声音就是节奏**：换层 = 纸滑声，换镜 = 撕纸/压印，情绪顶点 = 低频闷击 + 纸张震动。
- 音效总电平控制在 −18 ~ −24 dBFS（峰值 0.12–0.35），永远低于人声与伴奏，只做"触感"，不与歌曲抢位。

### 3.1 歌词层（全片共用）

- **版式**：居中下三分之一，基线 968 px，字号随字数自适应（56 / 50 / 44 / 40 px），字距 5 px。
- **材质**：一条宽 = 字宽 + 120、高 104 px 的**撕边纸条**做底衬（墨色 42–62% 渐变，始终轻微摆动 ±0.2°）；
  字是"贴"在纸上的纸片——先一层 3 px 偏移的硬投影，再叠纸白字，字身不带描边。
- **进出**：进字 = 从下方 26 px 落下并弹回（spring），出字 = 上移 16 px 淡出；换行不叠字。
- **可读性**：只在有字的时间段压一层底部渐变纱（0 → 52% 黑，45% 处起坡），无字时完全不压画面。
- **时间轴**：直接读 `.lrc` 的 43 行时间戳（`src/theme.ts` 的 `LYRICS`），一行显示到下一行前 0.08 s。
- **声音**：每句上屏配一声 5% 音量的纸张轻响（`paper_swish`），共 43 处。

## 4. 逐镜头脚本

### ① 00:00 – 00:30　窗阵隧道　「引子」

**意图**：把观众放进"一叠纸"里。深夜的城市是一列列窗户纸片，越往里越小，最深处只有一扇窗亮着——那台电视。

- **构图**：画面正中是一条向心隧道：8 层窗墙纸片层层后退（每层缩小 0.815、亮度递增），每层是一面 5×4 的窗格墙 + 一个居中的大开口，透视消失点在 (960, 500)。
- **图层**：夜纸渐变 → 8 层窗墙（由后向前绘制，共 ~120 扇窗）→ 最深处电视光 → 纸屑微粒。
- **运动**：
  - 0–6 s：全黑，一张纸的白色边缘从上方滑入（纸滑声），露出标题。
  - 6–14 s：标题《年少有为》以剪纸字形出现在最亮的窗格里，字幕条（作词/作曲/编曲/演唱：李荣浩）如纸带依次压入画面下缘。
  - 14–24 s：相机持续向心推进（scale 1.00→1.34），窗格纸片按 0.35 s 间隔滑入，成为"城市亮灯"。
  - 24–30 s：最深处那扇窗开始闪——电视的一次次闪白，频率渐快，最后一帧整屏过曝白（切镜）。
- **色彩**：`#070d18 → #2b4a63`，窗光 `#cfe0ee`，标题月白 `#f7f1e3`。
- **音效**：`paper_slide`（0.0）· `paper_swish` ×6（窗格滑入，0.35 s 网格）· `wind_low` 铺底 · `tv_static`（24.0 起，音量渐强）· `tv_off`（29.9 收尾"啪"）。

## 5. 转场规则

| 转场 | 手法 | 用在哪 |
|---|---|---|
| 过曝白 | 电视闪白冲到全白 | ①→② |
| 抽离 | 桌面物件向上滑出 | ②→③ |
| 撕开 / 合拢 | 中缝撕裂与闭合 | ③内部 |
| 纸皱扭曲 | 整张纸低频形变 | ③→④ |
| 坠黑 | 雨条加速 + 压黑 | ⑤→⑥（④→⑤ 用一束光收） |
| 压红 | 红纸盖下来 | ⑧→⑨ |
| 拉远成纸 + 印章 | 揭示"这是一张纸" | ⑨ 结尾 |

> 除上述以外，镜头之间是**硬切**（1 帧），切点全部落在歌词换气点上，不做淡入淡出。

## 7. 制作流程

1. `assets/gen_textures.py` → `public/tex/*.png`（纸纹三件套）
2. `assets/gen_audio.py` → `public/sfx/*.wav`（音效库，44.1 kHz / 16-bit）
3. `src/theme.ts`：时间轴、切点、调色板、镜头表
4. `src/paper/*`：纸层原语（`Paper` / `Camera` / 撕边与锯齿路径生成 / 各镜头的纸剪造型）
5. `src/shots/Shot01…09.tsx`：九个镜头，每个约 6–10 层纸
6. `src/cues.ts`：音效 cue sheet（每一处纸的动作对应一个声音）
7. 抽帧 QA（`analysis/qa_stills.py`：亮度/色彩/ASCII 缩略图）→ 全片渲染

## 8. 渲染管线（本机适配）

Remotion 自带的 ffmpeg 管道在这台机器上会以 `write EOF` 中断，所以拆成三步：

```bash
# 1) 画面：PNG 序列（不经过 Remotion 的 muxer）
npx remotion render NianShaoMV out/frames --sequence --image-format=png --concurrency=6

# 2) 声音：numpy 直接把原曲与全部音效混在一起（cue 表从 src/cues.ts 解析）
python assets/mix_audio.py          # -> out/mix.wav

# 3) 合流：ffmpeg 编码 H.264 + AAC
python assets/encode.py             # -> out/nian-shao-paper-mv.mp4
```

同一份 cue 表同时驱动 `<Audio>`（Remotion 预览用）与 `mix_audio.py`（成片用），
两边的音画同步是同一个数据源，不会漂移。

## 9. 校验

- 逐镜抽帧，检查构图、亮度分布、纸层是否漏画（`analysis/qa_stills.py` 输出 ASCII 缩略图与 3×3 亮度表）
- 音效层单独成轨（`mix_audio.py --sfx-only`）核对峰值与密度：音效层 RMS 比人声低约 18 dB，不抢歌
- 成片用 `ffprobe` 校验：8374 帧 / 30 fps / 279.147 s / H.264 + AAC
