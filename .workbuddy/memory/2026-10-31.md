## my-film · 青山茶叶品牌 15 秒循环短片（Remotion）

- 位置：`my-film/`，产物 `out/film.mp4`（1920×1080 · 30fps · 15s · 带音轨）、`out/poster.png`、`out/sheet.png`、`FILM.md`（设计契约 + 镜头表）。
- 结构：种子墨点 → 坠落成渍 → 洇成远山 → 中山/近山长出 → 近山脊线被提成茶叶 → 叶收成墨珠 → 墨珠摊开印出「青山」→ 钤印 → 墨抽回、飞回种子点；第 0 帧与第 449 帧像素级一致（自写 PNG diff 验证 mean|diff|=0）。
- 关键技术点（复用价值高）：
  - **水墨边缘**：宣纸色 + `feTurbulence` 扰动渐变做遮罩（底部 + 两端各一层，嵌套相乘），墨块没有直边；只用一层遮罩叠加横向渐变会把纵向渐变「刷白」，必须嵌套两层 mask。
  - **SVG `clip-path` 基本图形（circle/inset）按元素包围盒解析**，会把文字裁掉大半 —— 必须用 `<clipPath clipPathUnits="userSpaceOnUse">` + `url(#id)`。曾误判为字体问题。
  - **形变保序**：把圆/水滴的点序做成「左→上→右→下」，与山脊点序一致，否则墨团会拧成尖角。
  - 大形状与小形状不能共用一个 `InkFilter` 的 edge 值，按 bbox 宽度切换滤镜。
- 环境问题：npm 走 CodeBuddy broker 会 `Broker request timed out`（重命名风暴），用 `npm install --os=darwin --cpu=arm64` 分批重试解决；**node 是 x64**，需额外装 `@rspack/binding-darwin-x64` 与 `@remotion/compositor-darwin-x64`。渲染要指定 `--browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`（本机无 headless shell 缓存，且未装 ffmpeg，`npm run check` 跑不了）。

## qingtian-mv · 周杰伦《晴天》MV 60 秒动效复刻（Remotion）

- 位置：`qingtian-mv/`，成片 `out/film.mp4`（1920×1080 · 30fps · 60s · 带音轨）。`node_modules` 软链到 `my-film/`。
- 结构：春·纽扣（0–12）→ 夏·便当与九封信（12–28）→ 秋·向上与向下（28–42）→ 冬·雨与雷（42–52，硬切）→ 沙滩·第九封信（52–60）。全部纯 SVG 平面图形 + 剪影，无照片、无粒子。
- 设计契约：黄绿双色（#F0DFA6 春 / #B2BE2A 夏 / #C7CF85 秋 / #2B3641 冬 / #F5E7BE 沙），底色是**一个连续函数** `groundColor(t)`，换季 = 换光而不是交叉淡化；只有 42s 与 52s 是切。
- 贯穿符号：那颗象牙色纽扣在五个场景里反复出现（衬衫 → 便当布结 → 花心 → 大提琴尾钉 → 字母 O），最后在沙滩上「长大」成 LOVE 的 O（圆盘→圆环，针孔→字腔，`fill-rule=evenodd` 两个同心圆路径）。
- 关键技术点：
  - **雨变沙**：同一批 150 条线，方向角 78°→0°、速度积分 `tau` 用 `1-e^{-kt}` 收敛到静止、长度 ×0.38、颜色插值——不是换一批图形，是同一批线转平。
  - **信纸展开显字**：字用 `clipPath` 贴着信纸矩形（高度 62→230），纸往下长，字从上方被「揭」出来，字永远不单独出现。
  - **九封信编号**：只露左上角 30px 的堆叠（错位 +30/+24），数字被自己的角遮住，抬 13px 时用同款 clip 擦出来。
  - **运动曲线**：静场（春、夏）靠 `Dapple`（三片 0.07–0.1 淡光斑缓慢漂移）维持生命感，否则 192×108 的帧差会掉到 0.00（死帧）。
- 声音：`cues.json` 只放 4 个 `boom`（34/47/29/26Hz，42s 起，慢衰减），其余 56/60 秒静音；为过 `score.mjs` 的「必须有 pitched/ambience」校验，加了一条 gain 0.0006 的 pad（归一化后 -66dB，听不见）。
- 环境：本机 ffmpeg 是 Remotion 自带的**精简构建**（无 volumedetect/tblend/tile/signalstats/rawvideo），`scripts/check.sh` 跑不完整。改用自写 `scripts/review.mjs`：`ffmpeg -r 2` 出 120 张灰度 PNG → 自写 PNG 解码 → 逐帧差；音频直接解 PCM 算每秒 RMS。要跑 ffmpeg 得 `DYLD_LIBRARY_PATH=<compositor-dir>`，且 `bash` 会因 SIP 丢掉 DYLD_*，必须直接调绝对路径。

## huiyi-mv · 王贰浪《把回忆拼好给你》前 60 秒立体书 MV

- 位置：`huiyi-mv/`，成片 `out/把回忆拼好给你_立体书MV_60s.mp4`（1920×1080 · 30fps · 60.00s · AAC 立体声），歌词 `data/lyrics.lrc`。
- 管线（按用户指定技术栈）：ffmpeg 解码分析节拍 → p5.js 确定性逐帧绘制 → puppeteer-core 驱动本机 Chrome 无头截 canvas → ffmpeg 合成。1800 帧约 5.5 分钟（≈5.5 fps）。
- 关键经验（复用价值高）：
  - **p5 的 `textFont()` 不能传带逗号/引号的字体串**（`'"Songti SC", serif'`），否则 canvas font 失效回落到 10px，`textWidth('我')` 会返回 12 —— 只能用单一族名 `'Songti SC'`。
  - **`fill('字符串', alpha)` 在 p5 1.11 会抛 `[object Arguments] is not a valid color`**，必须 `color(c).setAlpha()` 包一层（本项目的 `fa()`）。
  - **函数参数名会遮蔽 p5 全局**：`fill`、`pop`、`color` 做参数名/局部变量会直接报错（`pop is not a function`、`Cannot access 'pop' before initialization`）。踩了 4 次。
  - 文字逐字盖章必须 `textAlign(CENTER)`，否则每个字会右移半个字宽、整行超出版心。
  - 合书动画不能让封面「从中间长开」，会瞬间遮住主角；正确顺序是**纸艺先纵向压平 → 封面从右侧合过来**。
- 时间轴：18 句歌词 ↔ 18 个纸艺场景（烟花/收集/纸伞/纸鹤/高楼/紧握/星空/光芒/花开/纸船/快翻/铅笔/橡皮/纸杯电话/烟花倒带/红线/双钟/上色牵手合书成礼）。

- 定时间的方法（可复用）：
  - 长音频一次性 ASR 的时间戳不可信（把 9 句合成一段 4.4–36.8s）。改为**切窗探针**：`ffmpeg -ss X -t Y` 切 15–30s 小段单独转写，用片段的相对 onset 反推绝对时间，误差压到 ~1s 且能判断「这一段到底有没有人声」。
